How it works

Three steps, every lesson

1

Pick a board

Choose any of the six boards or the breadboard, spin it in 3D, and tap pins to see what each one does and why it matters.

2

Follow the wiring

Each lesson gives you a pin-by-pin wiring table. Match the colours, connect the virtual jumpers, and build the circuit step by step.

3

Run the simulation

Press Run and watch LEDs light, motors turn and readings stream into the serial monitor — then tweak the code and run it again.

CircuitLab 3D is an original educational project, built to help ECE students learn by doing.

Pin data and board specifications are summarized from the official documentation published by Arduino, Espressif and the Raspberry Pi Foundation.
